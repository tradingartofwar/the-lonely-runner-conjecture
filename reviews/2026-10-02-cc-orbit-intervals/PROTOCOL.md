## Frozen construction and selection

For each unique primitive pair P,Q appearing in the fresh inputs, build the complete first-eight safe core in [0,1] using exact boundary events and midpoint predicates. Build all cores before evaluating r queries. This function takes only P,Q. Save every interval and isolated point, its source geometry and labels. Preprocessing is constructed and charged within this run; it is not inherited free input.

Compare three fixed source policies:

| Policy | Retained source components | Purpose |
| --- | --- | --- |
| widest | One maximum-width component, earliest start on ties | Test severe compression chosen without r |
| all_components | Every component, descending width then earliest start | Complete core recovery, retaining isolated points |
| positive_only | All strictly positive-width components | Ablation of isolated equality points |

All policies use the same exact first-safe-band formula, all primitive clock lifts and physical time recovery. Evaluate each component once per case, retain the complete hit-bit list, and choose each policy's first successful source in its fixed order. Store exact witness time, normalized time, core clock, lift, phases, and physical laps for each distinct selected component. This full matrix is an evaluation design, not an optimized dispatcher benchmark. An all-components recovery is never counted as a widest success.

For empty cores, report EMPTY and all policies fail at 1/8. For isolated-only cores, retain and test the points; the positive-only policy has no candidates. Do not silently substitute a positive interval or reinterpret a missing 1/8 witness as a failure at 1/10.
