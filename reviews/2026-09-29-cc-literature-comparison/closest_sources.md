## Exact translation and the new obligation

The following comparison is our algebraic deduction from the displayed
definitions, not a claim that either source proves the extension.

| Item | Translation |
| --- | --- |
| Native coordinates | (x,y) maps to (x,y,x+y,2x+y,3x+y,3x+2y) modulo one |
| Integer parameters | d=gcd(p,q), (A,B)=(p/d,q/d)=(P,Q); no sign or permutation is needed |
| Clock | Source primitive time tau gives the original scaled family's time t=tau/d |
| Scope assumptions | Positive p!=q makes the six source entries positive and pairwise distinct |
| Distance convention | Source D(T)=1/2−ML; our threshold ML>=1/8 translates to D<=3/8 |
| Runner convention | Source n counts relative moving speeds; our total count is n+1, including the selected zero reference |
| Added coordinate | 5x+2y=(2x+y)+(3x+y), but its distance band is an additional constraint |

Permutations and independent sign changes preserve nearest-integer distances;
common scaling changes the clock. None of these operations deletes a seventh
distinct nonzero coordinate. Being an integer sum of two old coordinates
does not make a distance constraint redundant.

Specifically, write F6(t) for the minimum over the first six distances. The
new objective is F7(t)=min(F6(t),||(5p+2q)t||). Hence max F7<=max F6;
a lower bound or a maximizing time for F6 does not automatically lower-bound
F7. The archived control (p,q)=(1,4) makes this exact: at t=4/13 the first-six
phases are (4,3,7,11,2,5)/13, all at distance at least 2/13, while the seventh
speed is 13 and its phase is zero. This calculation uses an existing declared
control and requires no optimizer or new scan.

For the actual seven-dimensional torus generated by
(1,0,1,2,3,3,5) and (0,1,1,1,1,2,2), the first two coordinates make the
parameter map injective and give a saturated integer lattice: an integral
linear combination has integer coefficients because its first two entries
are those coefficients. Thus the general two-dimensional-torus framework is
available for a future spectrum computation. It supplies no automatic
transfer of the six-coordinate spectrum or witness times.
