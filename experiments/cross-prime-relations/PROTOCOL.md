# Shared short relation across two prime grids

A fixed reference has $k=n-1$ positive distinct integer speed differences (signs may also be chosen consistently per coordinate). A grid is blocked if no grid time attains the ordinary target $1/n$. Test whether one common coefficient vector, meeting both bounds in Beck and Everett's Theorem 2.1, can be orthogonal to the same labelled speeds modulo both primes. A pair can be discarded as a candidate for tightness or failure only after excluding every such vector. A compatible vector is inconclusive.

**Predictions.** The identical labelled consecutive rows retain a short relation. Pairing the first row $1,\ldots,n-1$ with its reversal forces the coefficient sum to be zero once both primes exceed $(n-1)(2n+1)$. This eliminates the reversed pairing. Forgetting the order identifies the two inputs. A rule that eliminates an unordered pair after testing one pairing is therefore unsound.

**Panel fixed before computing.** For five total runners use primes 47, 53 and every signed permutation of the second row (384 maps, including globally equivalent maps). For 16 runners use primes 503, 509, the identical and reverse controls, and 256 signed permutations using Python's Random(20261124). For each draw shuffle a fresh list 1 through 15 and independently change each sign when getrandbits(1) is one. Count each of the generated alignments once, with no substitutions. Each individual prime is blocked throughout the panels because all unsigned rows are consecutive. Measure separately whether the combined prime-product grid gives an ordinary lonely time.

**Verification.** At five runners enumerate all vectors satisfying both bounds up to a global sign. At 16 runners an explicit coefficient vector within the bounds proves compatibility. Try vectors of 1-norm 3 or 5 first. The reverse control has the symbolic exclusion above. Report inconclusive for any further alignment not certified in either direction. Verify a rational witness directly for every combined-grid success. For the identical control use both literal consecutive speeds and an all-odd integer lift with exactly the same residues. Report each panel separately and distinguish individual runner, aligned pairs and entire unordered cases. The 16-runner panel is a reproducible constructed sample.
